metrics used across this project. Cited in-line, near the code that will
eventually implement each one.

- Sharpe, W. F. (1994). The Sharpe Ratio. *Journal of Portfolio
  Management*, 21(1), 49-58.
- Freund, Y., & Schapire, R. E. (1997). A Decision-Theoretic
  Generalization of On-Line Learning and an Application to Boosting.
  *Journal of Computer and System Sciences*, 55(1), 119-139.
